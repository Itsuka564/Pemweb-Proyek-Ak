# Pembagian Tugas Tim

| Role | Nama | Tanggung jawab |
|---|---|---|
| Project Manager (PM) | [Isi nama] | Analisis, timeline, koordinasi, pemantauan, dokumentasi, testing |
| Frontend Developer (FE) | [Isi nama] | Implementasi UI, komponen, form, dashboard, integrasi API |
| Backend Developer (BE) | [Isi nama] | PostgreSQL/Supabase, autentikasi, otorisasi, API, logika bisnis |

## Project Manager
- Menyepakati ruang lingkup dan prioritas bersama tim.
- Membuat timeline dan pembagian pekerjaan.
- Memantau progres dan mencatat kendala.
- Mengelola GitHub Projects/issues.
- Menyiapkan skenario pengujian dan mengoordinasikan testing.
- Menjaga dokumentasi dan laporan tetap diperbarui.

## Frontend Developer
- Setup Next.js dan JavaScript.
- Mengimplementasikan 12 halaman rancangan.
- Membuat komponen UI, navigasi, form, tabel, dan dashboard.
- Menghubungkan UI dengan API backend.
- Menangani validasi tampilan, responsivitas, dan bug frontend.

## Backend Developer
- Menyiapkan Supabase/PostgreSQL dan skema database.
- Mengatur autentikasi dan hak akses berdasarkan role.
- Membuat API menggunakan Next.js Route Handlers.
- Mengembangkan CRUD aset/tarif dan proses penyewaan.
- Menerapkan validasi aturan bisnis, keamanan, dan error handling.

## Tanggung jawab bersama
- Review kode dan pengujian fitur.
- Melaporkan pekerjaan selesai, pekerjaan berjalan, kendala, dan target berikutnya.
- Melakukan integrasi secara bertahap.

## Alur kerja fitur
1. Tim menyepakati kebutuhan dan kriteria penerimaan.
2. BE menyiapkan skema data/kontrak API.
3. FE membangun UI (boleh memakai mock data sementara).
4. FE dan BE melakukan integrasi.
5. PM mengoordinasikan pengujian dan pencatatan bug.

**Catatan:** Isi nama anggota dan sepakati pembagian ini bersama tim.
